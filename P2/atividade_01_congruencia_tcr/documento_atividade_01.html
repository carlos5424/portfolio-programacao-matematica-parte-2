1. Objetivo e descrição do problema

O objetivo desta atividade é implementar, em Python, procedimentos matemáticos para verificar congruências modulares e resolver sistemas de congruências pelo Teorema Chinês do Resto. O programa recebe os valores digitados pelo usuário, mostra os cálculos intermediários, verifica as condições necessárias e apresenta a solução.

A atividade foi dividida em duas partes: (A) verificar se dois inteiros são congruentes módulo um inteiro positivo; e (B) resolver um sistema formado por três ou quatro congruências com módulos positivos e coprimos dois a dois.

2. Parte A — Verificação de congruência modular

Dois inteiros a e b são congruentes módulo n quando a diferença entre eles é divisível por n. Portanto, o programa calcula a diferença e o resto da divisão por n.

Critério: a ≡ b (mod n) ⇔ (a − b) % n = 0, com n > 0.

Exemplo 1 — Congruência verdadeira

Para a = 23, b = 8 e n = 5:

a − b = 23 − 8 = 15
15 = 3 × 5 + 0
15 % 5 = 0
23 % 5 = 3 e 8 % 5 = 3

Como o resto da diferença é zero, 23 ≡ 8 (mod 5).

Exemplo 2 — Congruência falsa

Para a = 17, b = 6 e n = 4:

a − b = 17 − 6 = 11
11 = 2 × 4 + 3
11 % 4 = 3

Como o resto não é zero, 17 e 6 não são congruentes módulo 4.

3. Procedimento implementado na Parte A

  1. Solicitar os inteiros a e b.
  2. Solicitar o módulo n e repetir a entrada enquanto n não for positivo.
  3. Calcular a diferença a − b e o resto da divisão dessa diferença por n.
  4. Exibir a divisão no formato diferença = quociente × n + resto.
  5. Concluir se os números são congruentes ou não.

Teorema Chinês do Resto

O programa permite escolher um sistema com três ou quatro congruências. Antes de resolver, verifica se todos os módulos são positivos e se o MDC de cada par de módulos é igual a 1. Essa é a condição de coprimalidade exigida nesta atividade.

4. Procedimento matemático

Considere um sistema de congruências:

x ≡ a₁ (mod n₁), x ≡ a₂ (mod n₂), ..., x ≡ aₖ (mod nₖ).
  1. Calcular o produto total N = n₁ × n₂ × ... × nₖ.
  2. Para cada congruência, calcular Nᵢ = N / nᵢ.
  3. Encontrar o inverso multiplicativo de Nᵢ módulo nᵢ, por meio do algoritmo de Euclides estendido.
  4. Calcular a soma S = a₁N₁u₁ + a₂N₂u₂ + ... + aₖNₖuₖ, em que uᵢ é o inverso encontrado.
  5. Reduzir a soma módulo N: x₀ = S % N.
  6. Substituir x₀ em todas as congruências para conferir a solução.
Solução geral: x = x₀ + tN, em que t ∈ ℤ.

5. Exemplo 1 — Sistema com três congruências

x ≡ 2 (mod 3)
x ≡ 3 (mod 5)
x ≡ 2 (mod 7)

Os módulos 3, 5 e 7 são coprimos dois a dois. O produto total é N = 3 × 5 × 7 = 105.

inᵢaᵢNᵢ = N/nᵢInverso uᵢTermo aᵢNᵢuᵢ
132352140

37215130

S = 140 + 63 + 30 = 233. Assim, x₀ = 233 % 105 = 23.

Conferência: 23 % 3 = 2; 23 % 5 = 3; 23 % 7 = 2. Todas as congruências são satisfeitas.

Resultado: x = 23 + 105t, com t ∈ ℤ.

6. Exemplo com quatro congruências

x ≡ 1 (mod 2)
x ≡ 2 (mod 3)
x ≡ 3 (mod 5)
x ≡ 2 (mod 7)

Os módulos 2, 3, 5 e 7 são coprimos dois a dois. O produto é N = 2 × 3 × 5 × 7 = 210.

nᵢaᵢNᵢInverso uᵢTermo
211051105
32701140
53423378
72304240

S = 105 + 140 + 378 + 240 = 863. Logo, x₀ = 863 % 210 = 23.

Conferência: 23 % 2 = 1; 23 % 3 = 2; 23 % 5 = 3; 23 % 7 = 2.

Resultado: x = 23 + 210t, com t ∈ ℤ.

7. Explicação da implementação

  • Entrada e validação: a função de leitura aceita somente inteiros; o programa repete entradas inválidas e não aceita módulo zero ou negativo.
  • MDC: foi implementado com divisões sucessivas pelo algoritmo de Euclides, sem usar math.gcd().
  • Inverso modular: é calculado pelo algoritmo de Euclides estendido, atualizando os coeficientes até encontrar o inverso.
  • Teorema Chinês do Resto: os produtos, inversos e termos são calculados com laços; ao final, o resultado é reduzido módulo N e testado em cada equação.

9. Resultado e conclusão

O programa atende às duas partes da atividade: verifica congruências usando o resto da divisão e resolve sistemas de três ou quatro congruências quando os módulos são coprimos dois a dois.
